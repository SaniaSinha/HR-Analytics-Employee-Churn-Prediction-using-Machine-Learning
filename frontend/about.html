About the Project

An intelligent machine learning system for employee attrition analysis.

Project Overview

Employee attrition is an important challenge for organizations. Losing employees can increase recruitment costs, affect productivity, and impact organizational performance.

This project develops a machine learning-based HR analytics system that predicts whether an employee is likely to leave an organization using employee-related information.

The application compares 21 machine learning experiments using three data sampling strategies and seven classification algorithms.

Sampling Strategies

Machine Learning Approach

The project evaluates three sampling strategies:

  • BASE – Original imbalanced training dataset
  • SMOTE – Synthetic Minority Over-sampling Technique
  • SMOTE-ENN – Combined over-sampling and data cleaning

Seven classification algorithms are evaluated under each strategy:

  • Logistic Regression
  • K-Nearest Neighbors
  • Support Vector Classifier
  • Decision Tree
  • Random Forest
  • AdaBoost
  • XGBoost

Automatic Model Selection

The application automatically selects the experiment with the highest F1-score among all 21 evaluated experiments.

The selected experiment is used to generate employee churn predictions. The prediction page displays the predicted outcome, churn probability, selected experiment, and its F1-score.
